일정 추가하기

  • 달력의 날짜 칸을 누르거나 위쪽 일정 추가 버튼을 눌러요.
  • 시작·종료 날짜를 다르게 하면 여러 날에 걸친 막대로 보여요.
  • 반복: 매일 · 매주 · 매월 · 매년.
  • 알림: 시작 시간을 정하면 정시 ~ 1일 전에 Windows 알림이 떠요.
  • 색상은 일정 막대와 메모 카드 색이 돼요.
  • 상태(시작 전 · 진행 중 · 완료)를 달면 일정 막대 오른쪽에 회색 · 파랑 · 초록 점이 생겨요.

메모

  • 날짜를 비워 두고 저장하면 달력에 뜨지 않는 일반 메모가 돼요.
  • 메모 리스트 열기로 모든 메모를 카드로 봐요.
  • 검색하거나 전체 · 즐겨찾기 · 오늘 · 날짜 있음으로 골라 볼 수 있어요.
  • 폴더: 메모 리스트 위쪽의 + 폴더로 만들고, 폴더를 누르면 그 폴더 메모만 보여요. 선택한 폴더에서 이름 바꾸기 · 삭제(메모는 남아요)도 할 수 있어요.
  • 카드 속 체크박스는 열지 않고 바로 체크돼요.

사이드 고정 메모

  • 편집 창에서 사이드에 항상 고정을 켜면 화면 가장자리에 탭이 생겨요. 다른 프로그램 위에도 늘 보여요.
  • 탭을 누르면 메모가 펼쳐져요. 체크하거나 편집 · 고정 해제를 할 수 있어요.
  • 탭 위치(모니터 · 왼쪽/오른쪽)는 위쪽 버튼이나 설정에서 바꿔요.

창 다루기

  • 투명도를 낮추면 배경만 투명해져서 바탕화면 위젯처럼 쓸 수 있어요.
  • 버튼으로 창 위치를 고정하면 실수로 끌려가지 않아요.
  • 위쪽 막대를 끌면 창이 움직이고, 가장자리를 끌면 크기가 바뀌어요.
  • ‹ › 로 달을 넘기고, 오늘로 돌아와요. 칸이 좁으면 날짜 옆에 +N으로 남은 일정 수가 보여요.

테마

  • 설정 → 테마에서 기본 · 그라데이션 · 민트 피아노 · Y2K 윈도우 중에 골라요.
  • 그라데이션은 배경 3색과 강조색을 직접 바꿀 수 있어요.
  • 사이드 고정 메모에도 같이 적용돼요.

저장 · 업데이트

  • 메모는 이 PC에만 저장돼요. 인터넷이 없어도 돼요.
  • 새 버전이 나오면 자동으로 받아서 알려 줘요. 아래쪽 업데이트 버튼을 누르고 다시 시작하면 적용돼요.
  • 설정 → 업데이트에서 직접 확인할 수도 있어요.
  • 써 보고 좋았던 점 · 불편한 점 · 버그는 아래쪽 피드백 보내기로 알려 주세요.
